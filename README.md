# 📊 AI Business Insight Generator

Transform CSV data into business insights using AI and SQL.

This application allows users to upload any CSV dataset, automatically load it into SQL Server, ask questions in plain English, and receive:

- SQL query generated by AI
- Query results from SQL Server
- AI-generated business insights based on the results

The goal is to make business data easier to explore without writing SQL manually.

---

# 🚀 Features

- Upload any CSV dataset
- Automatically detect table schema
- Load data into SQL Server
- Ask questions in natural language
- AI converts questions into SQL queries
- Execute SQL on SQL Server
- Display query results instantly
- Generate business insights using Groq AI
- Clean and interactive Streamlit interface

# ⚙️ How It Works

1. Upload a CSV file.
2. The application previews the dataset.
3. Load the data into SQL Server.
4. Ask a business question in plain English.
5. Groq AI generates the SQL query.
6. SQL Server executes the query.
7. The application displays the results.
8. Groq AI generates business insights from the output.
